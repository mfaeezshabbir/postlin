# Copilot Instructions for Postlin Setup

We are building **Postlin**, an AI-powered LinkedIn assistant.

Tech stack:
- Next.js 15 (App Router) + TypeScript + Tailwind
- MongoDB + Prisma
- Google Gemini AI API
- BullMQ (Redis) for background jobs
- Resend for transactional emails
- NextAuth for authentication (LinkedIn OAuth)
- Modular folder structure

Generate:
1. A clean modular folder structure in the Next.js app:
   - `/modules/auth`
   - `/modules/drafts`
   - `/modules/notifications`
   - `/modules/publisher`
   - `/modules/users`
   - `/modules/analytics`
   - `/lib` (shared utils)
   - `/workers` (BullMQ queues/workers)

2. Basic Prisma schema for MongoDB:
   - `User`
   - `Post`
   - `Preference`
   - `Activity`
   - `Analytics`

3. Boilerplate configuration files:
   - `.env.example` with `DATABASE_URL`, `RESEND_API_KEY`, `GEMINI_API_KEY`, `LINKEDIN_CLIENT_ID`, `LINKEDIN_CLIENT_SECRET`, `REDIS_URL`
   - `docker-compose.yml` with services for MongoDB and Redis
   - `prisma/schema.prisma` configured for MongoDB
